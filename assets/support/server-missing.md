The servers page lists the servers where you have **Manage Server**, and the servers with {bot} where you can time out, kick or ban members. Other permissions, such as Manage Channels, are not enough.

### If a server is missing
1. Ask the server's owner or an admin to give you a role with Manage Server, or with Timeout, Kick or Ban Members to moderate it.
2. Reload the [servers page](/guilds). The list comes from Discord and refreshes within a minute.

### If only the moderation screens open
Without Manage Server, a server is listed under **Ready to moderate**, and only its members, warnings, cases, bans and appeals open. {bot}'s settings for that server need Manage Server.

### Other labels you might see
- **Add** means you can invite the bot to that server yourself.
- **No permission** means somebody with Manage Server has to add it.
- A server where the bot has been removed shows an invite rather than its settings.
