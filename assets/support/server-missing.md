The servers page lists the servers where you have **Manage Server**, and the servers whose admins gave you some of their dashboard screens. Other permissions, such as Manage Channels or Ban Members, are not enough.

### If a server is missing
1. Ask the server's owner or an admin for a role with Manage Server, or to give you the screens you need on its **Dashboard access** screen.
2. Reload the [servers page](/guilds). The list comes from Discord and refreshes within a minute.

### If only some screens open
A server listed under **Shared with you** opens only the screens its admins gave you. Ask one of them if you need another.

### Other labels you might see
- **Add** means you can invite the bot to that server yourself.
- **No permission** means somebody with Manage Server has to add it.
- A server where the bot has been removed shows an invite rather than its settings.
