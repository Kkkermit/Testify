{bot} speaks English, German, Spanish, French, Italian, Russian, Dutch and Japanese.

### In Discord
The descriptions in the slash command menu and the right-click actions under **Apps** follow the language your Discord is set to, in **User Settings**, **Language**. So do the messages every command shares: why a command was refused, a cooldown, and the apology if something breaks. The commands keep their English names, like `/help`, so everybody types the same thing.
- A prefix command, like `{prefix}help`, cannot tell which language you use, so it follows the server's language, which a server's owner sets in **Server Settings**, **Community**.
- Most of what a command answers is still in English.

### On the dashboard
Choose a language on the [Appearance](/appearance) page, or from the website's header. The dashboard remembers it in your browser.
