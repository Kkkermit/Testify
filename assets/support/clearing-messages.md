`/clear` deletes up to 100 recent messages in the channel you run it in. It needs **Manage Messages**.

- Give the number of messages to delete, from 1 to 100.
- Add a user to delete only their messages.

`{prefix}purge` and `{prefix}prune` work as prefix aliases.

> **Tip:** Discord will not bulk delete messages older than two weeks.
