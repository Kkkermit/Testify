### Work through these
1. **Is it online?** The [status page](/status) says whether it is, and how quickly it is answering.
2. **Can it see the channel?** It needs **View Channel**, **Send Messages** and **Embed Links** there. A channel's permission overrides are the usual cause.
3. **Is the command switched on** for this server, under **Commands** on the dashboard?
4. **For prefix commands**, is it this server's prefix, and are prefix commands switched on? Mention the bot to find out.

If a command does reply with a message, that message says what is wrong: a missing permission, a cooldown, or a switched-off command.
