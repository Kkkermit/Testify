title: Changing the prefix
keywords: prefix, change prefix, set prefix, t?, text command prefix, custom prefix
---
The prefix is what goes in front of a text command, such as `{prefix}help`. Each server has its own.

- In Discord, run `/prefix` to see it, and give it a new value to change it. This needs **Manage Server**.
- On the dashboard, open your server’s **Settings** and change it under **Prefix**.

Slash commands are not affected, and still start with `/`.
