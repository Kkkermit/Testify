1. **Check the prefix.** Mention the bot on its own and it replies with this server's prefix.
2. **Check prefix commands are on.** A server can switch them off so only slash commands work. It is under **Command prefix** on the dashboard's **Settings** page.
3. **Check the bot can read and reply** in that channel.

> **Tip:** Slash commands keep working either way, so try `/help`.
