You need the **Manage Server** permission in a server to add a bot to it.

1. Sign in to the dashboard and open the [servers page](/guilds).
2. Find the server under **Add**. Servers where you do not have Manage Server are listed under **Needs somebody else**.
3. Press **Add**. Discord shows its own consent screen with that server already chosen.
4. Check the permissions and press **Authorise**.

The servers page refreshes within a minute, and the server moves to **Ready to configure**. The bot asks for a fixed set of permissions rather than Administrator, so it can only do what its features need.
