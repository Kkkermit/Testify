Every warning, timeout, kick, ban, softban and unban is a numbered case, whether it came from a command, the dashboard or a warning's automatic step.

### Looking one up
- `/case view` shows one case by its number.
- `/case list` shows the server's latest cases, or one member's when you name them.

Both need Moderate Members, and both answer only you.

### Posting cases to a channel
Run `/case log` with a channel, which needs Manage Server. Each new case is posted there as it happens, and nobody it names is pinged. Run it with no channel to stop.

### On the dashboard
Open your server, then **Cases** under Moderation. Search by case number, a member's name or ID, or the reason, and narrow the list to one kind of action.

> Warnings given before cases existed are listed too, without a number.
