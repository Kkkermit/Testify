A server can switch music off, or keep the player for a few roles.

- **In Discord:** run `/music system`. It needs **Manage Server**.
- **On the dashboard:** open your server, then **Music** under Entertainment.

### DJ roles
With no DJ roles ticked, anybody can use the player. Tick some, and only members holding one of them can run music commands.

> **Tip:** People with Manage Server can always use the player, whatever the DJ roles say. Turning music off, though, turns it off for everybody.
