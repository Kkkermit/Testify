A server can switch music off, or limit the player to a few roles.

- In Discord, run `/music system`. This needs **Manage Server**.
- On the dashboard, open your server and choose **Music**.

With no DJ roles chosen, anybody can use the player. People with Manage Server can always use it, whatever the roles say. When music is switched off, it is off for everybody.
