Every command works two ways, and both do the same thing.

- **Slash commands**: type `/` in any channel and Discord lists them, along with the options each one takes.
- **Prefix commands**: type the prefix and the command as ordinary text, for example `{prefix}help`. The prefix is `{prefix}`.

Many commands have shorter prefix aliases too, such as `{prefix}bal` for `/balance`. The [command list](/commands) shows every command, its options and its aliases. In Discord, `/help` does the same.
