Every command works two ways, and both do exactly the same thing.

### Slash commands
Type `/` in any channel. Discord lists the commands and shows the options each one takes as you fill it in.

### Prefix commands
Type the prefix and the command name as an ordinary message, for example `{prefix}help`. Options follow in order, separated by spaces, and the last one can contain spaces.

- The prefix is `{prefix}` unless your server changed it.
- Many commands have short aliases, such as `{prefix}bal` for `/balance`.
- Mention the bot on its own to be told the prefix in that server.

### Finding commands
- `/help` in Discord lists every command, category by category.
- The [command list](/commands) on the dashboard is searchable and shows every option.

> **Tip:** A server can turn prefix commands off completely. Slash commands always keep working.
