Each server has its own economy, so money earned in one server stays there.

### Getting started
1. Run `/economy create` to open an account. You start with {fact:economy.startingWallet} in your wallet.
2. Earn money with `/daily`, `/work`, `/beg` and more.
3. Check it with `/balance`.
4. Spend it in `/shop`, and use what you own from `/inventory`.

`/cooldowns` shows when each way of earning is ready again, and `/economy-info account` shows everything about an account.

> **Tip:** Keep savings in the bank. Robbers can only take what is in your wallet.
