Any command can be switched off in your server without removing the bot.

### Steps
1. Open your server on the dashboard.
2. Choose **Commands** in the sidebar.
3. Use the switch beside the command. Search by name or alias to find it quickly.

A switched-off command refuses to run, as a slash command and as a prefix command, for everybody in that server, and says so.

> **Tip:** `/help` cannot be switched off, because it is how members find out what is still available.
