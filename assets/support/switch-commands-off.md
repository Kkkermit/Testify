id: switch-commands-off
title: Turning off a command
keywords: disable command, turn off command, switch off, block command, remove command, hide command, enable command, turn on
---
Any command can be switched off for your server without removing the bot.

1. Open your server on the dashboard.
2. Go to **Commands** in the sidebar.
3. Use the switch beside the command.

A switched-off command refuses to run, as a slash command and as a prefix command, for everybody in that server. `/help` cannot be switched off, because it is how members find out what is left.
