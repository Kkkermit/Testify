Some commands can only be used every so often, and the message says how long is left.

- A command's page, found with `/ask`, says how often it can be used.
- Economy commands such as `/daily`, `/work` and `/rob` have their own timers. `/cooldowns` lists yours.

Cooldowns are per server, so waiting in one server does not affect another.
